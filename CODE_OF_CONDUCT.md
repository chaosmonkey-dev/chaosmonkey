# Code of Conduct

## Our pledge

We pledge to make participation in the ChaosMonkey community a respectful,
harassment-free experience for everyone, regardless of experience level,
identity, or background.

## Expected behavior

- Be constructive and assume good intent.
- Stay technical — critique code and ideas, not people.
- Respect maintainer decisions on scope and direction.
- Welcome newcomers; this project is meant to be used and learned from.

## Unacceptable behavior

- Harassment, personal attacks, or discriminatory language.
- Publishing others' private information.
- Submitting code that intentionally exfiltrates data or weakens security.

## Enforcement

Report conduct issues privately to the repository maintainers via GitHub (open a
confidential report through the maintainer's profile or the repository's
security advisory channel). Maintainers will review and may warn, moderate, or
ban participants whose behavior violates this code. Maintainers' decisions on
enforcement are final.

Adapted from the Contributor Covenant, version 2.1.
